# CCIE SP Workbook Solutions

**These are the FULL versions of WB01–WB16 with complete solutions.**

Each file contains:
- **Question** — what to configure
- **Solution** — complete IOS-XR config + explanation of WHY
- **Verification** — show commands + what to look for

## When to use these

1. **Try the task yourself first** using the question-only version in the parent folder
2. If stuck for more than 15 minutes, check the solution here
3. After completing a task, compare your config with the solution — there may be multiple valid approaches
4. Focus on understanding the **explanation** sections, not just copying config
